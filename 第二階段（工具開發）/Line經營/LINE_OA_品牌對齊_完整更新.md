## 一、品牌調性落差總覽

在開始貼文案之前，先理解這次改了什麼、為什麼改。

### 需要修正的問題

| 項目 | 舊版（好宅通） | 新版（擇居） |
|------|--------------|-------------|
| 品牌名稱 | 好宅通 | 擇居 |
| 品牌人格 | 熱心教練 | 冷靜同行者 |
| 語氣 | 「我幫你」「教你」「攻略」「必看」 | 「值得想清楚」「你可以」「慢慢來」 |
| 標點 | 大量驚嘆號 | 幾乎不用驚嘆號 |
| Emoji | 每段都有 🏠💰📋🔍💪🎉 | 極少使用，偶爾用一個作為視覺錨點 |
| 自稱 | 「你的買房教練」「AI教練」 | 不自稱，或說「擇居」 |
| CTA 語氣 | 「馬上開始」「立刻取得」 | 「如果你準備好了」「可以從這裡開始」 |
| 連結域名 | homerun-taiwan.com | howhouse.tw |
| 產品架構 | 通用買房攻略 | 三大工具：我的決策性格、我的買房地圖、我的財務診斷 |
| Rich Menu 風格 | 6 色彩色方塊 | 應與網站一致：暖白底、金棕色調、乾淨排版 |

### 語氣轉換原則

- 不說教、不指導、不替使用者決定
- 用「選擇」取代「步驟」，用「想清楚」取代「搞懂」
- 不用「一定要」「千萬別」「小心」這類恐嚇式措辭
- 句子結尾不加驚嘆號
- 保持安靜、溫暖、留有空間的節奏

### 7. 房貸

- **標題：** 房貸
- **關鍵字：** `房貸`、`貸款`、`利率`

```
房貸是買房裡最大的一筆長期支出，
多了解一些，對做決定會有幫助。

幾個基本概念：

貸款成數：一般可貸 7-8 成，首購族條件好的話可能更高
利率類型：固定利率前幾年穩定，機動利率隨市場浮動
目前房貸利率大約在 2.0%-2.5% 左右（2026 年）
還款方式：本息均攤每月金額固定，本金均攤前期較高但總利息較少

寬限期是前 2-3 年只繳利息不繳本金，
結束後月付會明顯增加，這個要提前算好。

建議至少問 3-5 家銀行比較條件，
不同銀行的利率和手續費差異不小。

→ howhouse.tw/step/02.html
```

- **標題：** 稅費
- **關鍵字：** `稅費`、`稅`

```
買房的費用不只有房價，

買房之後每年還有：
房屋稅（5 月）和地價稅（11 月）

如果未來賣房，房地合一稅的稅率和持有年限有關，
持有越久稅率越低，自住滿 6 年有 400 萬免稅額。

### 10. 實價登錄

- **標題：** 實價登錄
- **關鍵字：** `實價登錄`、`房價`、`行情`

```
實價登錄是出價前最重要的參考依據。

查詢網址：lvr.land.moi.gov.tw

查的時候留意這幾件事：

選同社區或同路段，篩選近 1 年內的交易
注意看的是「主建物」坪數，不是總坪數

同社區不同樓層、座向，單價可以差 10-15%
預售屋和成屋的實登不能直接拿來比

登錄有 1-2 個月的時間差，最新的交易可能還沒上去。
親友間的交易價格通常偏低，不太有參考性。

帶著實價登錄的數據去談價，
至少知道自己出的價在什麼範圍。

→ howhouse.tw/step/04.html

### 13. 斡旋與出價

- **標題：** 斡旋出價
- **關鍵字：** `斡旋`、`要約`、`出價`

```
出價有兩種方式，差別值得先了解。

斡旋金：
付一筆錢（通常 5-10 萬）給仲介去和屋主談。
成交的話這筆錢轉為定金；沒成交全額退回。
要注意的是，屋主一旦同意，你反悔的話斡旋金可能被沒收。

要約書（內政部版）：
不用先付錢，只簽書面意向。法律效力和斡旋金相同。
彈性比較大，通常會建議優先考慮這個。

出價的時候可以參考：
先用實價登錄了解行情範圍
第一次出價可以從行情的 85-90% 開始
每次加價幅度不要太大
自己心裡要有一個天花板價，到了就停

不買，也是一個好的決定。

輸入「合約」了解簽約前的注意事項
→ howhouse.tw/step/10.html
```

### 14. 合約

- **標題：** 合約
- **關鍵字：** `合約`、`簽約`

```
簽約前你有法定的契約審閱期，至少 5 天。
這段時間值得好好用。

合約裡需要確認的事：

標的資訊：地址、坪數、有沒有含車位
付款方式和時程
交屋日期，以及延遲交屋的罰則
瑕疵擔保：賣方對漏水、結構問題的保證範圍

常見的風險：
「現況交屋」意味著賣方不負瑕疵責任
違約金不對等
交屋日期寫「另行約定」等於沒有保障
口頭承諾不算數，要寫在合約裡

如果有不確定的條款，花幾千塊找律師看一下，
通常是值得的。

→ howhouse.tw/step/10.html

### 15. 驗屋

- **標題：** 驗屋
- **關鍵字：** `驗屋`、`交屋`

```
驗屋是交屋前確認房屋狀況的最後機會。

## 七、Rich Menu 視覺設計方向

### 配色

| 元素 | 色碼 | 說明 |
|------|------|------|
| 整體背景 | #FAFAFA | 與網站一致的暖白色 |
| 格線分隔 | #E5E5E5 | 1px 細線分隔，與網站 architectural grid 一致 |
| 主標文字 | #121212 | 深色，清楚可讀 |
| 副標文字 | #8B7355 | 低調的棕色，與網站步驟計數器同色 |
| 圖示 / 重點 | #B8956A | 擇居的金棕色品牌色 |
| 不使用的顏色 | 藍紅紫橘綠青 | 舊版的 6 色方塊完全捨棄 |

### 排版風格

- 每格背景 #FAFAFA，格與格之間用 1px #E5E5E5 線分隔
- 每格內容：左對齊或置中，上方一個 Lucide 風格的線條圖示（金棕色）
- 主標用 Noto Sans TC Bold，約 28-32px
- 副標用 Noto Sans TC Regular，約 16-18px，#8B7355
- 整體感覺：像是網站的一部分，而不是另一個設計系統

### 圖示建議（Lucide icon 風格，線條 1.5px）

| 格子 | 圖示概念 |
|------|---------|
| 決策性格 | compass 或 fingerprint |
| 買房地圖 | map 或 route |
| 財務診斷 | calculator 或 coins |
| 18 步路徑 | list-ordered 或 milestone |
| 建商查核 | building-2 或 search |
| 問擇居 | message-circle 或 help-circle |

### 尺寸

- 2500 x 1686px（LINE 大尺寸 6 格版型）
- 輸出格式：PNG
- 3×2 格配置

### 和舊版的差異

舊版用了 6 個不同的飽和色塊（藍、紫、綠、紅、橘、青），視覺上非常跳。
新版統一為暖白底 + 金棕色線條圖示，和網站的設計語言完全一致——
安靜、乾淨、不花俏，一看就知道是同一個品牌。
