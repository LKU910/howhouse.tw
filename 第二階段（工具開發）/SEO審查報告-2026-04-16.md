# 擇居 howhouse.tw SEO 深度審查報告

**日期：** 2026-04-16  
**審查範圍：** 全站技術 SEO、Google 收錄狀態、品牌搜尋可見度

---

## 一、核心結論：Google 完全沒有收錄你的網站

這不是「排名不好」或「排名很後面」的問題。`site:howhouse.tw` 搜尋回傳**零結果**。搜尋 `howhouse.tw`、`"擇居" 買房`、`"howhouse.tw"` 也完全找不到你的網站。

Google 目前根本不知道 howhouse.tw 存在，或者知道但還沒完成索引。

### ❌ 需要修正的問題

#### 問題 1：零 Google 收錄（最嚴重）

**可能原因：**

1. **DNS 遷移太新** — 2026-04-14 才從 Cloudflare Pages 遷移到 Vercel，Google 還沒來得及爬
2. **Search Console 可能未正確提交 sitemap** — 驗證碼存在，但不確定是否有在 Search Console 後台主動提交 sitemap.xml
3. **舊域名 homerun-taiwan.com 的歷史權重可能沒有正確轉移**
4. **零外部反向連結** — Google 沒有任何外部路徑可以發現你的站

**需要你確認的事項：**
- 你有沒有登入 Google Search Console (https://search.google.com/search-console) 並看到 howhouse.tw 的資源？
- 裡面 sitemap 那一欄，有沒有提交過 sitemap.xml？狀態是什麼？
- 「涵蓋範圍」或「頁面」那一欄，顯示多少頁面已索引？多少被排除？

#### 問題 2：首頁 H1 不含品牌名

目前首頁 H1 是：
```
每一步
都值得想清楚
```

H1 是搜尋引擎判斷頁面主題最重要的標籤之一。首頁 H1 應包含品牌名「擇居」。

**建議改為：**
```
擇居——每一步，都值得想清楚
```
或在 H1 下方加一個 `<p>` 明確寫出品牌定位。

#### 問題 3：首頁 hero 描述是 JS 動態填充

```html
<span id="heroDesc"></span>
```

這個 span 是空的，內容靠 JavaScript 填入。Google 雖然可以執行 JS，但對於關鍵 SEO 內容，最好是直接寫在 HTML 裡，不要依賴 JS 渲染。

**建議：** 把 hero 描述直接寫成靜態 HTML。

#### 問題 4：首頁及大部分頁面缺少 og:image

只有 quiz.html 和 quiz-result/ 頁面有 og:image。以下頁面都沒有：

- index.html（首頁）
- about.html
- builders.html
- trends.html
- 所有 step/ 頁面
- 所有 builder-*.html 頁面

缺少 og:image 會導致社交分享顯示空白預覽圖，降低點擊率和分享意願。

**建議：** 製作一張通用 OG 圖（1200×630px），包含擇居 logo + 標語，所有頁面都加上。

#### 問題 5：外部品牌訊號為零

搜尋 `"howhouse.tw"` 和 `"擇居" 買房 台灣`，Google 回傳的結果中完全沒有 howhouse.tw。也找不到任何外部網站提及或連結到你的站。

這代表 Google 沒有任何第三方訊號來確認這個網站的存在和重要性。

#### 問題 6：品牌詞搜尋被干擾

搜尋「擇居」會被香港居屋（居屋買賣）、中國的「择居」App 等結果淹沒。搜尋 `howhouse` 會撞到 twhouse.com、how-house.org 等無關網站。

在這種品牌名稱有干擾的情況下，你需要更強的品牌定錨策略。

## 三、改善計畫（按優先順序執行）

### 第一優先：讓 Google 知道你存在（本週內）

**動作 1：確認 Google Search Console 設定**
1. 登入 https://search.google.com/search-console
2. 確認 howhouse.tw 資源已驗證（用 google4b94b9fc9e6e305a.html 或 meta tag）
3. 到「Sitemap」頁面，提交 `https://howhouse.tw/sitemap.xml`
4. 到「網址檢查」，輸入 `https://howhouse.tw/`，點「要求建立索引」
5. 對以下重要頁面也做同樣操作：
   - https://howhouse.tw/builders.html
   - https://howhouse.tw/trends.html
   - https://howhouse.tw/step/01.html
   - https://howhouse.tw/about.html
   - https://howhouse.tw/quiz.html

**動作 2：確認 Bing Webmaster Tools**
1. 登入 https://www.bing.com/webmasters
2. 用 msvalidate.01 meta tag 驗證
3. 提交 sitemap
4. Bing 的索引速度通常比 Google 快，可以先建立搜尋存在感

**動作 3：在 Google 建立品牌連結**
1. 如果有 FB 粉專，確認「關於」裡面的網址是 howhouse.tw
2. 如果有 LINE OA，確認描述和連結指向 howhouse.tw
3. 考慮建立 Google 商家檔案（Google Business Profile），即使不是實體店面也可以

### 第二優先：修正技術 SEO 問題（本週內）

**動作 4：首頁 H1 加入品牌名**

修改 index.html 的 H1，例如：
```html
<h1>擇居<br><span>每一步，都值得想清楚</span></h1>
```

**動作 5：首頁 hero 描述改為靜態 HTML**

把 `<span id="heroDesc"></span>` 替換為直接寫死的文字，例如：
```html
<p>從釐清需求到拿鑰匙，18 個步驟陪你想清楚每個買房決定。建商查核、流程指引、市場趨勢，擇居是台灣首購族的買房決策工具。</p>
```

JS 可以在上面做效果，但初始 HTML 裡要有完整文字。

**動作 6：全站加上 og:image**

1. 製作一張通用品牌 OG 圖：`/og/default.png`（1200×630px）
2. 在所有缺少 og:image 的頁面 `<head>` 中加入：
```html
<meta property="og:image" content="https://howhouse.tw/og/default.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
```

**動作 7：清除 data-config.json 裡的「好宅通」殘留**

雖然 data-config.json 被 robots.txt 擋掉爬蟲，但為了品牌一致性，建議也清理。

### 第三優先：建立外部品牌訊號（兩週內）

**動作 8：建立可被索引的品牌頁面**

至少在以下平台建立頁面並連回 howhouse.tw：
- Facebook 粉絲專頁（已有的話確認連結正確）
- Medium 或 方格子（vocus）發一篇品牌介紹文
- LinkedIn 公司頁面
- GitHub 上的 repo（如果是 public）

每個頁面都要：
- 明確提到「擇居」和「howhouse.tw」
- 包含一段品牌描述
- 附上網站連結

**動作 9：在 PTT/Dcard 等平台自然分享**

在 home-sale 等看板或買房相關討論中，以提供價值的方式分享擇居的工具。不是硬宣傳，而是「這個建商查核工具蠻好用的 howhouse.tw/builders.html」。

### 第四優先：強化內容 SEO（一個月內）

**動作 10：About 頁面強化為品牌定錨頁**

目前 about.html 的 title 和 description 都不錯，但頁面內容需要包含：
- 擇居是什麼（一段 100 字以內的品牌定義）
- 為誰服務（首購族、換屋族）
- 和 591/信義/好房網的差異（決策工具，不是物件搜尋）
- 核心功能列表
- 團隊或品牌故事
- 常見問題 FAQ

這頁是讓 Google 建立「實體理解」最關鍵的頁面。

**動作 11：考慮增加 blog / 內容行銷頁**

靜態工具站不容易持續產生新內容讓 Google 爬。考慮增加一個 blog 或「買房知識」區塊，定期發布和關鍵字相關的文章，例如：
- 「2026 新青安貸款懶人包」
- 「遠雄建設評價整理」
- 「首購族買房前 10 個最常犯的錯」

這些長尾關鍵字是你最有機會搶到排名的入口。

## 五、你現在最該做的一件事

**登入 Google Search Console，確認網站已驗證，提交 sitemap.xml，並對首頁手動「要求建立索引」。**

沒有這一步，其他所有 SEO 優化都沒有意義，因為 Google 根本還不知道你在這裡。
