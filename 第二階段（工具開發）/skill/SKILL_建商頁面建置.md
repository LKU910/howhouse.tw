### 網路輿情（sec-sentiment）— 直連 + 存檔雙保險

輿情區塊的核心原則：**每一則摘要都必須能被讀者點一下就驗證**。做不到這點，寧可不放。

#### ⚠️ 環境限制

輿情蒐集流程需要直接存取 PTT、Mobile01、Dcard 等論壇網站，以及 archive.org 存檔服務。

- **Cowork**：sandbox 的 egress proxy 會擋住這些網域，**無法執行輿情蒐集**。Cowork 負責頁面的其他所有部分（MOEA 查詢可透過 Chrome 繞過、頁面結構、基本資料、建案列表等）。
- **Claude Code**：跑在本地終端機，網路不受限，**負責執行輿情蒐集 + archive.org 存檔**。

#### 蒐集流程（Claude Code 環境）

詳見 `sentiment-collector-guide.md`，摘要如下：

```
1. 用 curl/fetch 到 PTT、Mobile01 搜尋建商名稱
2. 逐篇讀取，找有實質討論的貼文（≥10 推文或 ≥5 個不同 ID 回覆）
3. 確認貼文 URL 可正常開啟
4. 對每個採用的 URL，呼叫 https://web.archive.org/save/{URL} 建立存檔快照
5. 等 Wayback Machine 回傳存檔 URL
6. 將直連 + 存檔連結 + 準確摘要寫入 builder-{slug}.html
```

#### 頁面呈現規則

- 每則輿情卡片放 **兩個連結**：
  - `查看原文 ↗` → 原始貼文直連
  - `存檔備份 ↗` → archive.org 快照連結
- 摘要內容必須忠實反映該篇貼文的討論方向，不可張冠李戴
- 正負比例反映真實搜尋結果，不硬湊平衡

#### 搜不到怎麼辦

如果某建商在公開討論平台上討論量極少（< 3 篇有實質內容的貼文），則：

```html
<div class="card">
  <div class="sec-label">輿情概況</div>
  <p style="font-size:14px;color:#666;line-height:1.7">
    {建商名稱} 在 PTT、Mobile01 等公開討論平台的討論數量極少，
    未達好宅通的收錄門檻（至少 3 篇含實質討論的貼文）。
    建議自行搜尋查閱。
  </p>
</div>
<!-- 只放搜尋入口連結，不放任何摘要 -->
```

這比硬湊三則「搜尋頁連結 + 模糊摘要」誠實得多。

#### 品質檢查

- [ ] 每則輿情的「查看原文」連結可正常開啟，內容與摘要吻合
- [ ] 每則輿情的「存檔備份」連結可正常開啟
- [ ] 沒有任何輿情卡片的連結指向搜尋頁面（搜尋頁只放在底部「自行搜尋」區）
- [ ] 正負比例沒有刻意平衡，反映真實搜尋結果
