## 更新步驟

### 1. 編輯 data-config.json
位置：`deploy/data-config.json`

修改對應的數值，例如央行升息後：
```json
"一般房貸利率": {
    "數值": "2.5%",    ← 改這裡
    "說明": "2026 年 Q3 水準",
    ...
}
```

同時更新 `_last_updated` 和 `_next_review` 日期。

### 2. 執行檢查腳本
```bash
cd homerun/
python3 update-data.py
```

腳本會告訴你哪些頁面引用了這些數據，以及是否有遺漏。

### 3. 手動修改 HTML
根據檢查報告，到對應的 HTML 檔案修改數值。

**為什麼不自動替換？** 因為同一個數字在不同上下文中意義不同，自動替換可能誤改。例如「40」可能是「40 年貸期」也可能是「40 坪」。

### 4. 更新免責聲明日期
每次更新數據後，修改 step 頁面免責聲明中的日期：
```
撰文時（2026 年 4 月）→ 撰文時（2026 年 X 月）
```

可用以下命令批次替換：
```bash
# 範例：將 2026 年 4 月 改為 2026 年 10 月
find deploy/step -name "*.html" -exec sed -i 's/撰文時（2026 年 4 月）/撰文時（2026 年 10 月）/g' {} +
```

### 5. 更新 sitemap 日期
```bash
sed -i 's/2026-04-08/2026-XX-XX/g' deploy/sitemap.xml
```

### 6. 重新部署

## 高風險數據提醒

以下數據如果錯誤，可能造成法律風險：

1. **新青安截止日** — 如果已過期但網站還寫「申請截止 2026/7/31」，讀者可能被誤導
2. **利率數字** — 讀者可能用錯誤的利率做貸款試算，導致預算失準
3. **保固年限** — 如果民法修正（目前結構 15 年），舊數字可能導致讀者錯失保固權益
4. **信用管制成數** — 央行隨時可能調整，錯誤的成數資訊影響買房決策

## 建議審閱時間點

- **每季初**（1月、4月、7月、10月）：配合央行理監事會議
- **央行公告升降息後 48 小時內**：更新利率相關數據
- **新青安截止日前 1 個月**：確認是否延長或結束
- **每年 2 月**：更新前一年六都交易量統計
