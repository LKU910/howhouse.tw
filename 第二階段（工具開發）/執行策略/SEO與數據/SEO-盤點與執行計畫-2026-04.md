## 二、發現的問題（按嚴重性排序）

### 🔴 嚴重：Google 完全未收錄

`site:howhouse.tw` 搜尋回傳零結果。搜尋 "howhouse.tw" 和 "擇居 買房" 也找不到任何 howhouse.tw 頁面。

**可能原因：**
1. 網站 4/14 才從 Cloudflare Pages 遷移到 Vercel，Google 可能還未重新爬取
2. sitemap.xml 的 `lastmod` 日期集中在 4/9 和 4/14，域名歷史很短
3. Google Search Console 可能未提交 sitemap 或未要求索引

**必要行動：**
- 登入 Google Search Console → 確認網站已驗證
- 手動提交 sitemap.xml
- 對首頁和 5 個核心頁面手動「要求建立索引」
- 確認 DNS 指向正確（Vercel CNAME）、無 redirect loop

### 🔴 嚴重：calculator.html 未列入 sitemap

財務診斷工具（calculator.html, 115KB 最大頁面）完全不在 sitemap.xml 中，Google 可能不會發現這個頁面。

### 🟡 中等：progress.html 設了 noindex

```html
<meta name="robots" content="noindex, nofollow">
```

這直接告訴 Google「不要收錄這個頁面」。如果買房地圖工具希望被搜到，這個 noindex 需要移除。

**判斷：** 如果是因為功能尚未完善而刻意設的，可以暫時保留。但一旦工具準備好，務必移除並加入 sitemap。

### 🟡 中等：quiz-result 頁面是跳轉頁，SEO 價值為零

8 個結果頁都包含：
```html
<meta http-equiv="refresh" content="0;url=https://howhouse.tw/quiz.html#result=steady_player">
<link rel="canonical" href="https://howhouse.tw/quiz.html">
```

它們只是社群分享用的 OG 跳板（讓 LINE/FB 預覽正確），完全不產生搜尋價值。

**判斷：** 這個設計對社群分享是正確的。但日後可以考慮把結果頁改為真正的獨立內容頁（每種人格 500～800 字的分析文），這樣 8 個結果頁就變成 8 個可被搜尋的長尾入口。

### 🟡 中等：builder-*-full.html 頁面未列入 sitemap

4 個建商的完整版頁面（baojia-full, farglory-full, hfd-full, sanfa-full）存在於 deploy/ 但不在 sitemap 中。

### 🟡 中等：guide/ 文章缺少 FAQ schema

4 篇指南中有 3 篇沒有 FAQ schema（只有 home-inspection-checklist.html 有）。FAQ schema 會讓 Google 搜尋結果出現展開式問答，顯著提升點擊率。

### 🟢 輕微：sitemap lastmod 日期未隨實際更新同步

多個頁面的 lastmod 仍停在 2026-04-09，但實際上 index.html 等頁面已在 4/16–4/17 更新過。不準確的 lastmod 會降低 Google 重新爬取的優先度。

### 🟢 輕微：缺少 guide/ 與三大工具之間的內容對應

目前 4 篇 guide 文章的主題：
1. 建商背景怎麼查（→ 對應 builders.html ✓）
2. 驗屋清單（→ 對應 inspection.html ✓）
3. 新青安貸款 2026（→ 獨立知識 ○）
4. 預售屋簽約注意事項（→ 獨立知識 ○）

三大核心工具沒有任何對應的 guide 入口頁：
- 我的決策性格（quiz.html）→ ✗ 無對應指南
- 我的買房地圖（progress.html）→ ✗ 無對應指南
- 我的財務診斷（calculator.html）→ ✗ 無對應指南

## 四、執行計畫（按優先順序）

### 第一波：基礎修復（本週完成）

這些是不需要產出新內容、只需改設定的修復項目：

**1. Google Search Console 確認與 sitemap 提交**
- 登入 GSC → 確認 howhouse.tw 已驗證
- 提交 sitemap.xml
- 手動要求索引：首頁、quiz.html、builders.html、calculator.html、tools.html
- 同時確認 Bing Webmaster Tools 也已提交

**2. 把 calculator.html 加入 sitemap.xml**
```xml
<url>
  <loc>https://howhouse.tw/calculator.html</loc>
  <lastmod>2026-04-17</lastmod>
  <changefreq>monthly</changefreq>
  <priority>0.8</priority>
</url>
```

**3. 把 4 個 builder-*-full.html 加入 sitemap（或設 canonical 指向主頁）**
- 如果 full 頁面和主頁內容高度重複，加 canonical 指向主頁
- 如果 full 頁面有獨立價值，加入 sitemap

**4. 更新 sitemap 所有 lastmod 日期為實際最後修改日期**

**5. 評估 progress.html 的 noindex**
- 如果工具已可用 → 移除 noindex，加入 sitemap
- 如果尚未準備好 → 保留，但建立提醒待移除

### 第二波：內容建設（2～4 週）

**6. 建立 guide/decision-personality.html**

「我的決策性格」的 SEO 入口頁。

- 目標關鍵字：買房性格測驗、買房心理準備、買房決策
- 結構：1,200～1,500 字指南 + CTA 導向 quiz.html
- Title：`買房總是猶豫不決？先認識你的決策性格｜擇居`
- Schema：Article + FAQ（3～4 個常見問題）
- 內部連結：→ quiz.html, → step/01.html, → step/02.html
- 加入 sitemap

**7. 建立 guide/buying-checklist.html**

「我的買房地圖」的 SEO 入口頁。

- 目標關鍵字：首購族買房步驟、買房 checklist、第一次買房
- 結構：2,000～2,500 字指南（用 18 步框架的 7 階段做骨架），嵌 progress.html CTA
- Title：`首購族買房完整步驟｜從心理準備到交屋的 18 步清單｜擇居`
- Schema：Article + FAQ + HowTo（18 步可以用 HowTo schema）
- 內部連結：→ progress.html, → 18 步各頁, → quiz.html
- 加入 sitemap

**8. 為 guide/ 現有 3 篇文章補上 FAQ schema**

builder-background-check.html、new-youth-loan-2026.html、presale-contract-checklist.html 都沒有 FAQ schema。每篇提取 3～5 個自然的問答對，加上 FAQPage schema。

### 第三波：強化連結結構（第 3～4 週）

**9. 在 18 步頁面之間建立交叉連結**

每步頁面的底部增加：
- 前一步 / 後一步的導航
- 對應 guide/ 文章的「延伸閱讀」連結
- 例如：step/05.html（建商信任）→ guide/builder-background-check.html

**10. 在 quiz 結果流程中增加內部連結**

quiz.html 的結果區塊應該根據人格類型，推薦不同的下一步：
- 穩健棋手 → 「你可能已經準備好了，來看看 18 步走到哪」→ progress.html
- 焦慮行動者 → 「先看清財務面」→ calculator.html
- 謹慎觀望者 → 「先釐清需求」→ step/01.html

**11. 在 calculator.html 加入 Schema**

calculator.html 目前沒有 structured data。可以加 `SoftwareApplication` 或 `WebApplication` schema。

### 第四波：外部能見度（持續性）

**12. vocus 文章 → howhouse.tw 導流連結**

已發佈的兩篇 vocus 文章中的 howhouse.tw 連結就是外部反向連結。後續每篇 vocus 文章都應該包含 2～3 個指向 howhouse.tw 不同頁面的連結。

**13. 社群平台建立 Profile Backlinks**

在以下平台建立擇居的 Profile，並放上 howhouse.tw 連結：
- Facebook 粉專（已有 LINE，確認 FB 也有）
- PTT、Mobile01 的簽名檔（自然參與討論）
- 方格子沙龍的外部連結（已設定 howhouse.tw ✓）

**14. 後續 guide/ 文章排程**

建議每 2 週產出一篇，依此順序：
1. guide/decision-personality.html（第一優先，藍海）
2. guide/buying-checklist.html（搭配買房地圖）
3. guide/down-payment-guide.html（搭配財務診斷）
4. guide/buy-vs-rent.html（搭配財務診斷）
5. guide/first-time-buyer-mistakes.html（通用長尾）
