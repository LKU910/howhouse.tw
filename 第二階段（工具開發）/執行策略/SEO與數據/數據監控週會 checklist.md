# 擇居｜每週 5 分鐘數據監控 checklist

> 建立日期：2026-04-21
> 目的：讓 Kuan 每週花最少的時間看最重要的數字，不被次要指標淹沒
> 使用時機：每週固定時間（建議週一早上）打開以下頁面各看 1 分鐘

---

## 看這四個地方就夠（每週 5 分鐘）

### 1️⃣ GA4 總覽 → 看有沒有長（1 分鐘）

**打開**：[analytics.google.com](https://analytics.google.com) → 擇居 property → 首頁報表

**看什麼**：
- **週活躍使用者（WAU）**：比上週是漲還是跌？
- **新使用者 vs 回訪使用者的比例**：回訪率高代表黏性
- **流量來源**：自然搜尋 / 直接 / 社群 / LINE 的占比

**警戒線**：
- 週活躍跌超過 20% → 查看近期是否有部署錯誤
- 流量幾乎全來自單一來源 → 風險集中，要分散

---

### 2️⃣ GA4 事件 → 看工具被用得怎樣（1.5 分鐘）

**打開**：GA4 → 左側「報表」→「參與」→「事件」

**看這幾個事件的計數（近 7 天）**：

| 事件 | 意義 | 健康基準 |
|---|---|---|
| `quiz_started` → `quiz_completed` | 測驗完成率 | > 50% |
| `calculator_loaded` → `calculator_full_completed` | 財務診斷完整跑完率 | > 25% |
| `progress_return_visit` | 回訪地圖 | 月月成長 |
| `calculator_high_burden_shown` | 顯示「負擔比超過 40%」警示 | 看趨勢，了解使用者財務現實 |
| `line_add_friend_clicked` | LINE 加入按鈕點擊 | 月月成長 |
| `tool_to_tool_jump` | 跨工具跳轉 | 觀察哪條路徑最通 |

**警戒線**：
- `quiz_started` 多但 `quiz_completed` 比例 < 30% → 測驗太長或某題卡住，用 Clarity 錄影找原因
- `calculator_level1_completed` 多但 `calculator_full_completed` 少 → 第二/第三層體驗有問題

---

### 3️⃣ Looker Studio 儀表板 → 看 18 步與建商熱度（1.5 分鐘）

**打開**：Looker Studio → 擇居儀表板 02（18 步熱度 + 建商熱度）

**看什麼**：
- **18 步各頁瀏覽量排行**：哪幾步最多人看？哪幾步幾乎沒人看？
- **18 步滾動完成率**：哪幾步讀到底的人少？內容可能太長或不吸引
- **25 家建商瀏覽量排行**：熱門建商是哪幾家？
- **`is_full_version=true` 的點擊率**：多少人會從簡版切到詳版？

**行動觸發**：
- 某一步完成閱讀率 < 30% → 這步的內容需要重寫
- 建商排行前 3 名跟預期不同 → 了解為什麼（可能反映真實市場熱度）
- 詳版使用率高 → 考慮把詳版內容整合進簡版

---

### 4️⃣ Microsoft Clarity → 看 3 個 session 錄影（1 分鐘）

**打開**：[clarity.microsoft.com](https://clarity.microsoft.com) → 擇居 project → Recordings

**看什麼**：
- 隨機挑 3 個過去一週的 session
- 特別優先看：「Rage clicks」「Dead clicks」「Excessive scrolling」標記的錄影
- 看使用者在哪裡遲疑、在哪裡滑回去、在哪裡關掉頁面

**行動觸發**：
- 看到同一個位置連續多個使用者猶豫 → UI 需要調整
- 看到有人快速滾動到底又滾回去找 → 結構不清楚
- 任何讓你「咦？」的行為 → 記下來，下次 iteration 處理

## 每月一次深度分析（約 30 分鐘）

### 每月第一個週一做

1. **GA4 探索（Exploration）**：
   - 建立「quiz → calculator → LINE 加入」的漏斗圖，看整體轉換率
   - 看「哪個人格的使用者最容易跳到 calculator」

2. **Clarity 熱圖**：
   - 首頁熱圖：看使用者到首頁後都點哪裡
   - tools.html 熱圖：看三工具哪個最吸引第一次點擊
   - calculator.html 熱圖：看哪些輸入欄位最多人碰，哪些被忽略

3. **對照競品**：
   - 快速看一下 591、House123、清華幫幫忙的最新內容趨勢
   - 擇居有沒有錯過重要話題

4. **紀錄到月報**：
   - 建立 `執行策略/數據月報/2026-XX.md` 放當月重點數字與觀察
   - 這份月報累積起來，未來談 B2B 授權或投資時有數據佐證

## 紅線與反應動作

| 情況 | 可能原因 | 立即動作 |
|---|---|---|
| GA4 數據完全消失 | 部署出錯或 analytics 被 block | 跑 `python tools/verify_analytics.py` 檢查 |
| Vercel 504/500 | 部署失敗或流量爆增 | Vercel Dashboard 看 logs |
| 某個工具完成率暴跌 | 上次改動壞了東西 | 用 Clarity 錄影確認異常行為，必要時 rollback |
| LINE 加入數歸零 | LINE OA 帳號有問題 | 自己打開 LINE 測試 |

---

## 不要做的事

- **不要每天看數據**：早期流量小，每日波動大，看了也沒判斷意義。每週看 1 次就好。
- **不要只看絕對數字**：比例與趨勢比絕對數字有用。
- **不要追求「漂亮」的指標**：與其優化 bounce rate，不如看「使用者跑完工具的比例」這類真正反映價值的指標。
- **不要因為單週下跌就改動產品**：至少觀察 2-3 週的趨勢再決定。
