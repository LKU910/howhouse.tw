# 好宅通 → 擇居：品牌轉換與網站改版執行規劃

> 制定日期：2026-04-14
> 目標：將 howhouse.tw 從「好宅通——台灣買房教練」全面轉型為「擇居」品牌，同步上線三大核心工具，完成從內容站到互動式決策系統的升級。

---

## 零、核心原則（貫穿所有工作）

這份規劃不只是「把好宅通三個字換成擇居」。品牌轉換的本質是語氣、立場、與使用者關係的全面重新校準。

**擇居的人格：冷靜的同行者**（不是教練、不是專家、不是推銷員）

| 維度 | 好宅通（舊） | 擇居（新） |
|------|-------------|-----------|
| 語氣 | 熱心、指導式、「必看」「攻略」 | 安靜、陪伴式、「值得想清楚」 |
| 立場 | 我教你怎麼買房 | 你在做一個重大選擇，我陪你想 |
| 驚嘆號 | 常用 | 不用 |
| CTA | 「開始第一步」「立即查看」 | 「選擇之前，先認識自己」「看看你走到哪了」 |
| 結構名 | 18 步就是 18 步（不變） | 頁面標題用決策視角問句 |

## 壹、品牌識別系統轉換

### 1-1. 文字商標

**現況：**「好<span style="color:#A67C52">宅</span>通」+ 副標「台灣買房教練」
**目標：** 以「擇居」二字為核心，需要決定——

- [ ] **字體處理**：沿用 Noto Serif TC 700，但「擇居」兩個字的氣質比「好宅通」安靜，可考慮降一級字重到 600，或增加字距（tracking-[0.3em]），讓品牌名呼吸感更足
- [ ] **重音字策略**：好宅通把「宅」染成銅色是強調「房屋」。擇居的核心動詞是「擇」——慎重選擇。建議「擇」字維持銅色 #A67C52 accent，「居」字用正常石色
- [ ] **副標替換**：「台灣買房教練」→ 需要一句話定位擇居。候選：
  - 「先擇，後居」（最短，呼應專案 CLAUDE.md 的宗旨）
  - 「買房是一連串的選擇」
  - 「陪你想清楚每個決定」

**需要 Kuan 決定：** 副標定稿、字重偏好

### 1-2. Favicon

現有 favicon.svg 需更新。擇居的 favicon 可以是：
- 「擇」字的極簡筆劃擷取
- 或一個幾何化的「門框/窗框」symbol，暗示居所

### 1-3. OG 圖片

目前 og/ 資料夾有 9 張人格測驗結果圖。品牌轉換後：
- 首頁、步驟頁的 OG 預覽圖需重製（目前無專屬 OG 圖）
- 人格結果頁 OG 圖需更新品牌名

## 貳、色彩與視覺微調

### 2-1. 色彩系統

現有建築師色盤（Architect Palette）與擇居的氣質相當契合——銅色的沉穩、石色的安靜、赭色的警示感都不需要大改。微調方向：

| 色彩 | 現值 | 調整建議 | 理由 |
|------|------|---------|------|
| 主色 Architect Bronze | #A67C52 | 可微調為 #B8956A（偏暖亮一階） | 「好宅通」的銅色偏沉，擇居作為陪伴者可以稍微溫暖 |
| 背景 Stone Light | #FAFAFA | 維持 | 安靜感的基底 |
| 正文 Stone Neutral | #121212 | 可考慮 #1A1A1A 或 #2A2A2A | 稍微降低對比，閱讀壓力更小，符合「不急」的氣質 |
| 次色 Architect Slate | #4A5D6A | 維持 | 用在工具、標籤上剛好 |

**需要 Kuan 決定：** 是否微調主色銅色的明度，或維持原色（改動很小，但影響整站感受）

### 2-2. 字體調整

字型家族不變（Noto Serif TC + Noto Sans TC），但排版節奏調整：

- **標題字距加大**：從 tracking-widest (0.1em) 統一提升到 tracking-[0.15em]，讓大標題更透氣
- **正文行高微增**：18 步內文頁的 line-height 從 leading-relaxed (1.625) 提升到 leading-loose (2.0)——目前手機版已有，桌面版也拉齊
- **引導語字級**：Hero 下方描述文字從 text-base 提升到 text-lg，讓語氣感更強

### 2-3. 元件風格微調

| 元件 | 現況 | 擇居調整 |
|------|------|---------|
| 步驟卡片 hover | 向上浮起 + 銅色邊框陰影 | 維持，但可以加一個極輕的左側銅色邊條（3px），呼應 phase-header |
| CTA 按鈕 | 底線文字連結風格（`border-b`） | 維持這個不搶眼的 CTA 風格，符合擇居不催促的語氣 |
| 打字機效果 | Hero 描述用 typewriter animation | 考慮移除或換成 fade-in，打字機效果偏「科技教學」，與擇居沉靜感有落差 |
| 建築師格線 | 1px gap grid (#E5E5E5) | 維持，這是好的視覺底層 |

## 參、全站文案改寫

這是工作量最大、影響最深的一塊。不是 find-and-replace「好宅通」→「擇居」就好，而是每一頁的語氣都要重新校準。

### 3-1. 全域搜尋替換（機械性）

以下是純文字替換，可用腳本批量處理：

```
「好宅通」→「擇居」         （出現在 nav, footer, title, og, schema, 版權聲明）
「HomeRUN」→ 移除            （Schema.org alternateName 裡還有）
「台灣買房教練」→ 新副標      （nav, footer）
「© 2026 好宅通」→「© 2026 擇居」
og:site_name → 擇居
Schema.org Organization name → 擇居
```

**注意：URL、域名 howhouse.tw 不變**——這是已經 index 的 SEO 資產，品牌轉換不動域名。

### 3-2. 首頁 Hero 文案重寫

**現況：**
```
沒買過房？
照著走就對了
```
這是教練語氣——「照著走就對了」預設了一個知道正確答案的引導者。

**擇居版本方向：**
```
買房，是一連串的選擇
每一步都值得想清楚
```
或更短的：
```
先擇，後居
```

Hero 下方描述文字（目前用 typewriter 動畫打出），改為靜態呈現：
```
從釐清需求到拿鑰匙，18 個步驟。
不急，一步一步來。
```

Hero CTA：
- 「開始第一步」→「選擇之前，先認識自己」
- 「或查看完整 18 步流程 ↓」→「或看看完整 18 步 ↓」

### 3-3. 18 步頁面標題語氣轉換

步驟的結構名稱不改（「第 N 步：XXX」），但每頁 h1 從教學式轉為決策式問句：

| 步驟 | 現有 h1 風格 | 擇居 h1（決策視角） |
|------|-------------|-------------------|
| 01 需求釐清 | 需求釐清：搞清楚自己要什麼 | 你想要的，跟你需要的，是同一件事嗎？ |
| 02 財務健檢 | 財務健檢：算清楚買得起多少 | 你能承受多少財務壓力？ |
| 03 認識房型 | 認識房型：預售、新成屋、中古 | 哪一種房子適合現在的你？ |
| 09 比較決策 | 比較決策：最後要選哪一間 | 兩個都不完美，你最在意什麼？ |
| 10 簽約須知 | 簽約須知：白紙黑字怎麼看 | 簽下去之前，哪些條款值得多看一眼？ |

其餘步驟依此邏輯逐一改寫。每個 h1 都應該是一個買房者真正會問自己的問題。

### 3-4. meta title / description 改寫

現有 title pattern：`{主題}｜首購族必看｜好宅通`
新 pattern：`{決策問句}｜買房 18 步第 N 步｜擇居`

- 移除「必看」「攻略」「全攻略」「一站搞定」等教練用語
- description 從「提供 XXX 指南」改為「幫你想清楚 XXX」

### 3-5. FAQ Schema 語氣調整

目前 FAQPage 裡的 Q&A 是知識庫風格，事實內容可保留，但措辭微調：
- 「首購族通常需要準備…」→「買第一間房，通常要準備到…」
- 移除任何「建議」開頭的句子，改用「可以考慮…」或「值得了解的是…」

## 肆、三大核心工具上線

### 4-1. 工具一：我的決策性格（買房方向診斷）

**狀態：** v2 設計規格已完成，計分矩陣已定義
**位置：** 首頁 Hero 區塊的主入口 + quiz.html

**執行重點：**

1. **整合至新首頁 Hero**
   - 「我的決策性格」成為首頁最顯眼的入口，位置在 Hero 主文案下方
   - CTA 文案：「選擇之前，先認識自己」
   - 不是另一個頁面的連結，而是整個首頁的核心行動

2. **HTML 計分邏輯與 Excel 矩陣同步**
   - v1 已知問題：scoringMap 與 quiz-matrix-v2.xlsx 不一致
   - 開發完成後必須跑驗證腳本，確保 8 種人格分佈均勻

3. **結果頁品牌化**
   - 8 種人格結果頁全部套用擇居語氣
   - 維度視覺化用水平長條圖（12 欄 grid，銅色填充）
   - 盲點描述用「值得留意的是…」句式，不打分不評判
   - 分享機制：LINE 分享 + 連結複製
   - 結果頁結尾的下一步入口：「看看你走到 18 步的哪了」（導向進度儀表板）

4. **SEO / 社群分享**
   - 每個人格結果頁有獨立 OG 圖
   - title 格式：`你是{人格名}｜買房決策傾向｜擇居`

### 4-2. 工具二：我的買房地圖

**目標：** 讓使用者追蹤自己走到 18 步的哪裡，建立回訪動機

**執行重點：**

1. **資料儲存**
   - 純前端 localStorage（無後端）
   - 結構：每步的完成狀態 + 時間戳 + 筆記欄位（optional）

2. **UI 設計方向**
   - 18 步以垂直時間軸呈現，已完成步驟有銅色勾選
   - 當前步驟放大顯示，附帶該步驟的核心決策問句
   - 整體感受像「安靜的進度條」，不是 gamification（不加徽章、不加分數）

3. **入口位置**
   - Nav 增加「我的買房地圖」入口（取代或並列「買房流程」）
   - CTA 文案：「看看你走到 18 步的哪了」

4. **與「我的決策性格」的串接**
   - 完成方向診斷後，根據人格建議的起始步驟，自動在儀表板上標記推薦起點

### 4-3. 工具三：我的財務診斷

**目標：** 解決最高痛點——「我到底買不買得起」，同時成為名單收集引擎

**執行重點：**

1. **試算範圍**
   - 基礎：月付金試算（本金、利率、年限）
   - 進階：總持有成本（含稅費、管理費、裝修預算）
   - 特色：新青安 vs. 一般房貸比較（從 data-config.json 抓即時數據）

2. **UI 設計方向**
   - 不是銀行的貸款計算機，是「決策視角的財務現實檢查」
   - 主問句：「這個決定的真實代價是什麼？」
   - 結果不只顯示數字，附帶一句擇居式的提醒（例：「每月還款佔收入超過 40%，生活品質會開始被壓縮。值得想一下。」）

3. **入口位置**
   - 首頁工具區塊（與我的決策性格並列）
   - Step 02（財務健檢）頁面內嵌
   - CTA 文案：「看清楚這個決定的代價」

4. **名單轉換機制**
   - 試算完成後提供「儲存結果到 Email」選項
   - 不強制，不彈窗，放在結果頁下方作為自然延伸

```
買房 18 步 | 決策工具 | 建商履歷 | 市場趨勢 | 關於擇居
```

（決策工具下拉含三項：我的決策性格、我的買房地圖、我的財務診斷）

**變動說明：**
- 「買房流程」→「買房 18 步」（更直接）
