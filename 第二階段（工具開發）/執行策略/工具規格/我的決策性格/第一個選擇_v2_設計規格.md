- Q1D：HTML 給 knowledge:1，Excel 給 knowledge:2

## 三、四維度人格框架

### 3.1 維度定義

#### 維度 A：決策風格（Decision Style）
- 學術來源：Schwartz, 2002 — Maximizer vs Satisficer
- 測量什麼：你是追求「最佳選擇」還是「夠好就行動」
- 光譜：極致比較者 ←→ 門檻行動者
- 買房意義：決定看房策略（看幾間才夠）和停損點（什麼時候該收手）

#### 維度 B：思考模式（Thinking Mode）
- 學術來源：Kahneman, 2011 — System 1 (快思) vs System 2 (慢想)
- 測量什麼：你靠感覺還是靠數據做判斷
- 光譜：直覺導向 ←→ 分析導向
- 買房意義：決定你需要什麼類型的資訊（感受型內容 vs 數據型工具）

#### 維度 C：風險態度（Risk Attitude）
- 學術來源：Kahneman & Tversky, 1979 — Prospect Theory 損失趨避
- 測量什麼：你更怕「買貴」還是更怕「錯過」
- 光譜：損失敏感（怕買貴/買錯）←→ 機會敏感（怕錯過/怕更貴）
- 買房意義：決定出價節奏和議價策略

#### 維度 D：掌控感（Perceived Control）
- 學術來源：Ajzen, 1991 — TPB 知覺行為控制
- 測量什麼：你覺得自己能不能搞定買房這件事
- 光譜：低掌控感（覺得複雜、不確定）←→ 高掌控感（覺得有把握）
- 買房意義：決定需要多少引導（高掌控→工具；低掌控→流程陪伴）

### 3.2 維度計分

每個維度 0–6 分，中位數 3。

- 0–2：光譜左側傾向明顯
- 3：中間
- 4–6：光譜右側傾向明顯

為了與結果路徑連結，保留一個輔助維度：

#### 輔助維度：購屋階段（Stage）
- 不構成人格軸，但影響「推薦從第幾步開始」
- 0–2：早期探索（步驟 1–4）
- 3–4：中期準備（步驟 5–9）
- 5+：後期決策（步驟 10–18）

## 四、12 題重新設計

### 設計原則

1. **情境題，不是知識題。** 每題描述一個買房場景，選項是不同的反應方式。沒有對錯。
2. **語氣安靜。** 不用「你知道嗎」「你有沒有」這種考試感的問法。用「如果…你會…」的假設語氣。
3. **每題主攻一個維度，輔攻另一個。** 確保每個維度至少有 3 題主攻。
4. **選項順序不暗示優劣。** 不要讓 A→D 看起來像從差到好。

### 頁面結構

- 第 1 頁：你現在在哪（Stage 定位 + 掌控感 D 探測）
- 第 2 頁：你怎麼想事情（決策風格 A + 思考模式 B）
- 第 3 頁：你怎麼面對壓力（風險態度 C + 綜合驗證）

## 六、結果系統重新設計

### 6.1 設計邏輯

v1 的結果是「你該從哪一步開始」（5 種固定路徑）。
v2 的結果是「你的買房決策人格」（人格標籤 + 維度解讀 + 對應路徑）。

結果頁結構：

```
1. 人格標籤（大標）
2. 一段話描述（你是什麼樣的決策者）
3. 四維度視覺化（雷達圖或長條圖）
4. 每個維度的具體解讀（這對你買房意味著什麼）
5. 你的判斷盲點（決策翻譯：基於組合模式的風險提醒）
6. 你的建議起點（連結 18 步）
7. 分享按鈕（人格標籤是社交貨幣）
```

### 6.2 人格類型

不做 2^4 = 16 種窮舉。用「主導維度 + 次要特徵」方式，定義 **8 種核心人格**：

| # | 人格標籤 | 主導特徵 | 次要特徵 | 典型行為 |
|---|---------|---------|---------|---------|
| 1 | **穩健棋手** | A 低（Satisficer）+ B 高（分析型） | C 高（損失敏感） | 用數據設框架，到了就行動。不怕慢，怕錯。 |
| 2 | **直覺獵手** | B 低（直覺型）+ A 低（Satisficer） | C 低（機會敏感） | 看對了就出手，憑感覺但很果斷。怕猶豫比怕買錯多。 |
| 3 | **完美主義者** | A 高（Maximizer）+ B 高（分析型） | C 高（損失敏感） | 資料永遠不夠，每個物件都想找到更好的。容易後悔。 |
| 4 | **焦慮行動者** | C 低（機會敏感）+ A 低 | D 低（低掌控） | 怕錯過所以想趕快行動，但又不確定自己判斷對不對。 |
| 5 | **謹慎觀望者** | C 高（損失敏感）+ D 低（低掌控） | A 高（Maximizer） | 覺得風險太大所以遲遲不動。想得多、做得少。 |
| 6 | **理性新手** | B 高（分析型）+ D 低（低掌控） | A 中 | 有研究精神但缺實戰經驗，需要結構化引導。 |
| 7 | **感性探索者** | B 低（直覺型）+ D 低（低掌控） | A 中 | 對「家」有很多想像，但不確定怎麼把想像變成行動。 |
| 8 | **從容決策者** | D 高（高掌控）+ A 低（Satisficer） | C 中 | 準備充分，心態穩定，需要的是比較框架而非基礎知識。 |

### 6.3 判定邏輯

```javascript
function getPersonaType(A, B, C, D) {
    // 正規化到 0-100
    const a = normalize(A);  // 決策風格（高=Maximizer）
    const b = normalize(B);  // 思考模式（高=分析型）
    const c = normalize(C);  // 風險態度（高=損失敏感）
    const d = normalize(D);  // 掌控感（高=高掌控）

    // 第一層：掌控感極端值
    if (d >= 70 && a <= 40) return 'composed';        // 從容決策者
    if (d <= 30 && c <= 30) return 'anxious_actor';    // 焦慮行動者
    if (d <= 30 && c >= 60) return 'cautious_observer'; // 謹慎觀望者

    // 第二層：決策風格 × 思考模式
    if (a <= 40 && b >= 60) return 'steady_player';    // 穩健棋手
    if (a <= 40 && b <= 40) return 'intuitive_hunter';  // 直覺獵手
    if (a >= 60 && b >= 60) return 'perfectionist';     // 完美主義者

    // 第三層：思考模式 × 掌控感
    if (b >= 50 && d <= 40) return 'rational_novice';   // 理性新手
    if (b <= 40 && d <= 40) return 'emotional_explorer'; // 感性探索者

    // 預設
    if (a >= 50) return 'perfectionist';
    return 'steady_player';
}
```

### 6.4 人格 → 18 步路徑對應

| 人格 | 建議起點 | 推薦步驟 | 理由 |
|------|---------|---------|------|
| 穩健棋手 | Step 9 | 09 → 07 → 08 | 你已經有框架，現在需要比較工具 |
| 直覺獵手 | Step 7 | 07 → 08 → 09 | 去看房吧，但帶著清單去，別空手 |
| 完美主義者 | Step 9 | 09 → 02 → 05 | 先建立比較框架，設好停損點再看 |
| 焦慮行動者 | Step 2 | 02 → 01 → 04 | 先算清楚，有數字你就不會被情緒帶著走 |
| 謹慎觀望者 | Step 1 | 01 → 02 → 03 | 從最不需要做決定的地方開始，慢慢建立信心 |
| 理性新手 | Step 3 | 03 → 05 → 06 | 你會研究，但需要知道該研究什麼 |
| 感性探索者 | Step 1 | 01 → 06 → 07 | 先把想像具體化，再去現場感受 |
| 從容決策者 | Step 9 | 09 → 10 → 14 | 你準備好了，直接進入比較和簽約準備 |

## 七、結果頁文案（擇居語氣）

### 語氣規範

- 不說「恭喜」「太棒了」「加油」
- 不打分、不排名
- 用「你傾向…」而非「你是…」（人格是傾向，不是標籤）
- 每個人格的盲點部分用「值得留意的是…」開頭
- CTA 用「從這裡開始看」而非「立即開始」

### 範例：穩健棋手

**標籤區**
```
你的決策傾向
穩健棋手
```

**描述**
```
你習慣用數據和邏輯做判斷，設好標準之後就能行動。
這在買房這件事上是很好的底子——你不容易被銷售話術帶走，
也不會因為「怕錯過」就倉促決定。
```

**盲點**
```
值得留意的是，你的理性有時候會讓你低估「住」這件事的感性面。
格局數據很好，但住起來舒不舒服，有些東西只有到現場站在那裡才知道。
建議你在數據篩選完之後，給自己一個「放空感受」的看房機會——
不帶清單，就在那個社區走一圈。
```

### 範例：焦慮行動者

**標籤區**
```
你的決策傾向
焦慮行動者
```

**描述**
```
你對「時機」很敏感——怕現在不買以後更貴，怕好物件被別人搶走。
這種感覺很真實，但它常常讓人在還沒準備好的時候就出手。
```

**盲點**
```
值得留意的是，銷售現場的「限量」「搶手」話術對你特別有效。
這不是你的問題——這是人類大腦的出廠設定（行為經濟學叫它「損失趨避」）。
兩個具體建議：
1. 出門前先寫下你的預算上限和底線條件，放在手機備忘錄。
2. 任何現場想做的決定，回家睡一晚再說。一晚之後還想要的，才是真的想要。
```
