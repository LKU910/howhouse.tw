## 四、發文流程

1. 進入 vocus 沙龍 → 內容作品管理 → 新增文章
2. 貼上 markdown 內容（vocus 支援 markdown 格式）
3. 填入標題、摘要、標籤
4. 選封面圖（可用 social-1200x630.png 或自選）
5. 發布設定選「公開」
6. 品牌文建議設為「置頂」
